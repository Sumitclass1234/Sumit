    A[Terraform Code] --> B[terraform fmt]
    B --> C[terraform init]
    C --> D[terraform validate]
    D --> E[terraform plan]
    E --> F[Code Review]
    F --> G[terraform apply]
    G --> H[Cloud Resources]
    H --> I[Monitor and Detect Drift]

Infrastructure as Code Principles

Keep infrastructure definitions in version control.

Use reusable modules for consistent deployments.

Separate development, testing, and production environments.

Protect remote state and restrict access.

Review Terraform plans before applying changes.

Use secure identity federation where supported.

Avoid hardcoding credentials or sensitive values.

Detect and investigate infrastructure drift.

Document infrastructure dependencies and recovery procedures.

<!-- ================= KUBERNETES WORKFLOW ================= -->

☸️ Kubernetes Deployment Workflow

flowchart TD
    A[Application Source] --> B[Build Docker Image]
    B --> C[Scan and Validate Image]
    C --> D[Push to Registry]
    D --> E[Helm or Kubernetes Manifest]
    E --> F[Deploy to Cluster]
    F --> G[Readiness and Liveness Checks]
    G --> H[Service and Ingress]
    H --> I[Monitoring and Logging]
    I --> J[Scale or Roll Back]

Kubernetes Operations Checklist

Verify node and cluster health.

Check Pod status and restart counts.

Inspect events and application logs.

Validate resource requests and limits.

Check readiness and liveness probes.

Verify Services, DNS, and network policies.

Review ingress and load balancer configuration.

Validate autoscaling behavior.

Confirm deployment and rollback procedures.

Review metrics, alerts, and capacity.
